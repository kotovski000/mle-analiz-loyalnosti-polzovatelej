# Исследование факторов удержания пользователей сервиса Яндекс Афиша


## Структура проекта

```text
├── data/                  # Локальные данные и справочники (в .gitignore)
│   ├── raw_afisha_data.csv         # Выгрузки из БД
│   └── final_tickets_tenge_df.csv  # Справочник валютных курсов
├── src/
│   └── processing.py      # Класс DataProcessor (логика загрузки, очистки и расчетов)
├── .env.example           # Шаблон переменных окружения
├── .gitignore             # Игнорируемые Git файлы
├── main.py                # Главный скрипт — точка входа в приложение
├── README.md              # Документация проекта
└── requirements.txt       # Зафиксированные зависимости окружения
```

## Инструкция по установке и запуску

### 1. Клонирование репозитория
Склонируйте проект и перейдите в его корневую директорию:
```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd <ИМЯ_ПАПКИ_ПРОЕКТА>
```

### 2. Настройка виртуального окружения
Создайте и активируйте виртуальное окружение:
```bash
python3 -m venv venv
source venv/bin/activate       # Для macOS / Linux
# venv\Scripts\activate       # Для Windows
```

Установите зависимости:
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 3. Переменные окружения (.env)
Создайте файл `.env` в корне проекта на основе шаблона `.env.example`:
```bash
cp .env.example .env
```

### 4. Подготовка данных
Поместите файл с курсами валют `final_tickets_tenge_df.csv` в директорию `data/`. При первом запуске сырые транзакции будут автоматически выгружены из базы данных по SQL-запросу и сохранены в `data/raw_afisha_data.csv` для ускорения последующих запусков.

### 5. Запуск приложения
Запустите конвейер обработки и формирования отчета одной командой:
```bash
python3 main.py
```

## Итоги анализа и бизнес-рекомендации

### Ключевые выводы
1. **Базовое удержание:** **61.28%** пользователей сервиса возвращаются за повторными покупками ($\ge 2$ заказов). При этом 75% клиентов оформляют не более 5 заказов.
2. **Точки входа:**
   - **Концерты** приводят наибольший объем новой аудитории (**44.7%** всех первых заказов) с удержанием **61.8%**.
   - **Выставки (64.3%)** и **театр (63.5%)** демонстрируют максимальную наблюдаемую долю повторных покупок.
   - **Спорт (54.9%)** и **детские ёлки (56.7%)** показали наименьший уровень возврата (гипотеза о повышенной лояльности спортивных болельщиков опровергнута).
3. **Географический фактор:** подтверждена гипотеза о региональном преимуществе — в топ-10 крупных регионах возврат составляет **62.5%** против **58.3%** в менее активных субъектах.
4. **Временной фактор:** день недели первого заказа практически не связан с вероятностью возврата клиента (наблюдаемый диапазон 59.5% – 62.8%).
5. **Факторы глубины лояльности:** корреляционный анализ $\phi_K$ показал заметную связь числа заказов со средним чеком (**0.281**) и слабую с регионом входа (**0.100**). Параметры первого устройства, категории события и дня недели практически не определяют количество последующих заказов.

### Практические рекомендации для маркетинга
- **Приоритет привлечения:** увеличить долю рекламных бюджетов на театральные и выставочные события — данная аудитория имеет наиболее высокую склонность к регулярным повторным покупкам.
- **Удержание аудитории концертов:** внедрить триггерные коммуникации с рекомендациями похожих артистов в первые 7–14 дней после первого посещения.
- **Кросс-маркетинг для спорта и сезонных событий:** протестировать спецпредложения на стендап-шоу и фестивали для спортивных болельщиков в межсезонье, а покупателям новогодних билетов предлагать весенние семейные активности.
- **Фокус на среднем чеке:** ориентировать программы лояльности на стабильный средний сегмент **400–700 руб.** за заказ, отказавшись от субсидирования экстремально дешевых билетов (до 150 руб.), клиенты которых редко становятся постоянными.
- **Отказ от избыточной сегментации:** не тратить ресурсы на дифференциацию цепочек рассылок по дням недели первого заказа из-за отсутствия значимого эффекта на удержание.
